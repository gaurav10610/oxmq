# Security Policy 🔒

OxMQ takes the security of our distributed job queue engine and its users very seriously.

---

## Supported Versions

We provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability in OxMQ, **please do not disclose it publicly in GitHub Issues or Discussions.**

Instead, report vulnerabilities privately by emailing:
📧 **security@oxmq.io** or by creating a confidential GitHub Security Advisory in the repository.

### What to include in your report:
1. Description of the vulnerability and its potential impact.
2. Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
3. Any suggested remediations or patches.

### Our Commitment:
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide a timeline for assessing the severity and releasing a fix.
- We will credit you in the release notes (unless you prefer anonymity).
